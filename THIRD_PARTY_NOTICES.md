# Third-party notices

Agentic Mono JP is built from `Moralerspace Neon HW` v2.0.0. The generated font keeps the
upstream copyright and license notice block in its `name` table. This document
records the components named by that block and points to their upstream license
information. It does not replace `LICENSE` or claim endorsement by any upstream
project.

Agentic Mono JP itself is released under SIL OFL 1.1 with Reserved Font Name
`Agentic Mono JP`, as declared in `LICENSE`. `AgenticMonoJP` is the file and
PostScript-name stem, not an additional Reserved Font Name.
